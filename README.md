# AI 供应链决策中枢

面向制造业与物流企业的 AI 决策平台作品集。

## 🚀 在线预览
👉 https://anan0728.github.io/ai-supply-chain/

## 功能模块

| 模块 | 说明 | AI 能力 |
|------|------|---------|
| 需求预测 | 销量预测 + 动态补货 | 真实工作流（移动平均 + 安全库存） |
| 供应商智能风控 | 断供风险预警 + 处置闭环 | LLM 风险分析 + 知识图谱传导 |
| 物流路径优化 | 路径规划 + 在途监控 | 方案对比 + 收益量化 |
| 供应链控制塔 | 全局指标聚合 | LLM 诊断报告 |
